## 4. 更新约定（每轮任务必做）

- **改哪个域，就更新哪个分册**：新增/修改函数时，在对应分册补充或修订小节（路径 + 职责 + 关键函数签名 + 修改注意点）。
- **总纲同步**：模块地图状态列、快速定位表如有新增模块/功能，同步更新。
- **变更记录**：每轮任务在总纲 §6 变更记录顶部插入一行（版本 + 日期 + 变更内容 + 说明 + 关联文档版本）。
- **关联文档版本同步**：需求文档、技术栈规范、重构规范、README 版本表随轮次同步升级（见各文档变更记录）。
- **交叉引用规则**：正文引用统一写「分册名（或原编号）+ 小节」，如「见 使用手册-后端核心.md 原 §2.1」。
- **删除/重构**：函数被删除或改名时，同步删除/改写分册对应小节，避免手册滞后。

## 5. 跨模块关键流程

### 5.1 导入链路（两段式，v1.93 实施）

```text
POST /api/books → 1MB 分块流式写盘 + 增量 sha256 → import_service.import_book_file
  同步阶段：move 至 data/books/<file_id>/ → parse_book 章节入库 → 封面提取 → 秒回 {book, task_id}
  后台 import-background：页图并发渲染 → local_text 索引 → incremental_cross_book_graph（跨书增量）
  → vision 预提取（进度权重 40/40/20）
```

### 5.2 提问链路（对话/脑图共用上下文）

```text
POST /api/books/{id}/chat → prepare_chat_job
  章节上下文 + 选中段落/划线裁剪图 + RAG 检索 + Skill 匹配 + 三层画像 + 历史窗口
  → stream_chat（SSE start/delta/end/error）→ persist_chat 落库
```

### 5.3 归档链路（读完沉淀）

```text
POST /api/books/{id}/archive → archive_book_task
  PDF：rebuild_book_caches 视觉通读补齐全书页缓存（已并发化，v1.93）
  → generate_rag_skill（文本模型总结 RAG/Skill，版本+1 增量）
  → 标记读完 → 三层画像迁移/暖记忆 → post-classify 簇合并重命名
```

### 5.4 跨书图谱链路

```text
关键词共现余弦分 + 笔记加权 → 候选书对（按分截断 MAX_LLM_PAIRS）
  → LLM 打分增强（strength/direction/from_book/reasons，失败回退关键词分）
  → BookRelation 落库 → 聚类（tag→文件夹→领域；post-classify 后验精化）
  → 图谱联动 graph_sync 增量增改 RAG/Skill → 相关领域书入暖画像
```

### 5.5 PDF 页图与视觉提取链路

```text
渲染：render_pdf_pages（导入）/ get_or_render_page（阅读按需回退）→ data/books/<id>/pages/page_XXX.jpg
提问：ensure_window_caches [P-1,P,P+1] → 命中 page_text/page_XXX.md 直接读，缺失调多模态 LLM 提取落盘
归档：rebuild_book_caches 补全缺失页 → 页缓存全文作为 RAG/Skill 总结输入
```
