## 1. 数据结构设计

### 1.1 相似度图内存表示（纯 Python，零依赖）

```python
# 节点：书 ID（int）。固定规范：所有遍历一律 sorted(node_ids)，即 book.id 升序。
SimGraph = dict  # 具体结构如下（用 TypedDict 或普通 dict 均可）

graph = {
    "nodes": [12, 13, 15, ...],                 # 升序节点列表（参与领域聚类的书 id）
    "adj": {                                     # 邻接表：无向边双向存储
        12: {13: 0.214, 19: 0.102},             # adj[u][v] = Sim(u,v)，float，≥ τ_cluster
        13: {12: 0.214},
        ...
    },
    "shared_terms": {                            # 边依据（可解释性 + 命名/补边复用），可选但必须保留
        (12, 13): ["傅里叶变换", "级数"],        # key 恒为 (min(a,b), max(a,b))，共享规范词按权重降序 top5
    },
}
```

设计要点：

- **邻接表用 `dict[int, dict[int, float]]`** 而非边列表：连通分量遍历、LPA 邻居加权投票、删节点的局部重算都是 O(度数)；边列表在这三处都要重建索引。
- **边权即 Sim 值**（P1 的 IDF 加权余弦，0~1），不另存原始分。`shared_terms` 的 key 统一用 `pair_key(a,b)`（复用 `app/services/graph/edges.py` 已有的 `pair_key`，它保证 `(min, max)` 规范化）。
- 孤立点（无任何 ≥τ_cluster 边）**不进 `adj`**，但保留在 `nodes` 中——连通分量算法对孤立点输出单点分量，由上层归「其他」。
- 内存占用估算：300 书稠密情形边数上界 44,850；每双向条目约 100 字节（int key + float + dict 开销），约 9 MB；加 `shared_terms`（每条 ≤5 个短字符串）≤ 30 MB。实际 IDF 压制后边数远小于上界（预计 <5,000 条），内存 <3 MB。

### 1.2 书籍→节点 ID 映射与簇结果结构

- **映射**：不新建映射表。节点 ID 直接用 `Book.id`（int），成图时从「待领域聚类书集合」构造 `nodes`；需要书名/关键词时经 `books_by_id: dict[int, Book]` 查回。避免引入 book→node 的二次编号，消除一套翻译层。

## 2. 算法步骤（逐步伪代码）

### Step 1：成图

**输入**：待领域聚类书集合 `pending`（已经过 tag/文件夹过滤，即现行 clustering.py:326 处 `result[b.id] == ""` 的书）；每书特征向量 `W_b = canonical_terms(book_keywords(b, 80))` 再 IDF 加权（P1 产物，本步只消费）。
**输出**：`graph`（1.1 结构）。
**复杂度**：O(N²·k̄)，k̄ 为平均向量词数（top80 归一后约 60~80）。300 书 = 44,850 对 × ~30 次交集运算 ≈ 秒级（见 §4.3）。
**失败回退**：`book_keywords` 为空的书不入图，直接「其他」（与现行 clustering.py:334-336 行为一致）。

```python
def _build_sim_graph(db, pending, vectors):
    nodes = sorted(b.id for b in pending)            # 确定性：一律 id 升序
    adj = {}
    shared = {}
    for i, a_id in enumerate(nodes):
        wa = vectors.get(a_id)
        if not wa:
            continue
        for b_id in nodes[i + 1:]:                    # 上三角，天然无重复
            wb = vectors.get(b_id)
            if not wb:
                continue
            # 剪枝（见下）：共享规范词 < 2 必不建边，先做集合交
            common_terms = sorted(
                (t for t in wa if t in wb),
                key=lambda t: -(wa[t] + wb[t]),       # 权重和降序，确定性
            )
            if len(common_terms) < MIN_SHARED_TERMS:  # = 2
                continue
            sim = cosine_idf(wa, wb)                  # P1 的 IDF 加权余弦，纯函数
            if sim + FLOAT_EPS >= TAU_CLUSTER:        # 容差比较，见 §4.1
                adj.setdefault(a_id, {})[b_id] = sim
                adj.setdefault(b_id, {})[a_id] = sim
                shared[(a_id, b_id)] = common_terms[:5]
    return {"nodes": nodes, "adj": adj, "shared_terms": shared}
```

**复杂度控制与剪枝决策（300 书 O(N²) 可接受性论证）**：

- 44,850 对，每对只做一次 dict 交集 + 条件余弦。dict 交集平均 ~30 次哈希查找，纯 Python 约 2~5 µs/对 → 全量 **<0.3 s**；余弦仅在通过剪枝后计算（预计 <15% 的对），可忽略。**结论：不需要倒排索引级剪枝。**
- 但保留一道**共享规范词数剪枝**（上方 `len(common_terms) < 2` 提前 continue）：它同时是语义条件（对齐现行「概念共现」边的共享词 ≥2 要求），把余弦计算量再降一个量级。
- 若未来书数 >2,000（超需求上限 300 书 6 倍），再换倒排索引（term → book 集合，只对共享 ≥1 词的对算 Sim），本设计预留：`_build_sim_graph` 内部实现可替换，签名不变。

### Step 2：连通分量（基线，必选）

**输入**：`graph`。**输出**：`list[list[int]]`，各分量内 id 升序、分量间按首元素升序。**复杂度**：O(V+E)。

**实现 A：并查集（推荐，作为基线实现）**

```python
class _UnionFind:
    def __init__(self, nodes):
        self.parent = {x: x for x in nodes}
        self.rank = {x: 0 for x in nodes}

    def find(self, x):
        # 路径压缩（迭代式，避免递归深度限制；300 节点无压力但习惯上更稳）
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        while self.parent[x] != root:
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        # 按秩合并；秩同则取较小 root，保证代表元确定性
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True

    def components(self):
        comp = {}
        for x in sorted(self.parent):               # 遍历序固定
            comp.setdefault(self.find(x), []).append(x)
        return comp                                 # {root: [成员升序]}


def _connected_components(graph):
    uf = _UnionFind(graph["nodes"])                 # 孤立点自动成单点分量
    for u in graph["nodes"]:
        for v in graph["adj"].get(u, {}):
            if u < v:                               # 每条边只 union 一次
                uf.union(u, v)
    groups = sorted(uf.components().values(), key=lambda g: g[0])
    return groups
```

**实现 B：迭代 BFS（备选，用于对照测试）**

```python
def _connected_components_bfs(graph):
    seen, groups = set(), []
    for start in graph["nodes"]:                    # 升序起点 → 结果序确定
        if start in seen:
            continue
        queue, comp = [start], []
        seen.add(start)
        while queue:
            u = queue.pop(0)                        # 实现可用 collections.deque
            comp.append(u)
            for v in sorted(graph["adj"].get(u, {})):   # 邻居升序
                if v not in seen:
                    seen.add(v)
                    queue.append(v)
        groups.append(sorted(comp))
    return groups
```

**取舍说明（为何基线选 A）**：

| 维度 | 并查集（A） | BFS（B） |
| --- | --- | --- |
| 时间 | O(E·α(V))，近似线性 | O(V+E) |
| 与增量的契合 | union 天然支持「新书并入」；删书重算只需对受影响子图重建 | 增量场景同样要重跑遍历 |
| 代码量 | ~25 行 | ~15 行 |
| 缺陷 | 不支持删边（删书后必须对受影响分量**整体重建**，见 §3.2） | 同左 |

两者对连通分量的语义完全等价，**B 保留为单元测试的交叉验证实现**（断言两者输出一致），不进入生产主路径。

### Step 3：加权标签传播（增强，feature flag 可选，默认关）

**输入**：`graph`、`seed`（默认 0）。**输出**：`labels: dict[int, int]`（label 用「簇内最小 book.id」作规范名，确定性且无需字符串）。
**复杂度**：O(iter·E)，≤10 轮。
**失败回退**：任一异常或迭代不收敛（达 max_iter 仍在震荡）→ 回退 Step 2 连通分量结果（连通分量是 LPA 的粗粒度上界，回退安全）。

> 注：以下伪代码中 `cluster_weight` 与每轮内层「预计算」段落为**示意性写法**，正式实现要求见伪代码之后的「实现注意」4+1 条。

```python
def _weighted_lpa(graph, seed=0, max_iter=10, anti_absorb=1.05):
    nodes = graph["nodes"]                          # 已升序
    labels = {v: v for v in nodes}                  # 初始化：每人自成一簇（label=自身 id）
    if not graph["adj"]:
        return labels

    def cluster_weight(label):                      # 各簇当前「权重和」= 成员入边权和的一半…
        w = {}                                      # 实现：成员度数权重和 Σ_{u∈簇} Σ_{v∈N(u)} sim
        for u in nodes:
            if labels[u] == label:                  # 下方循环中实际按成员累加，此处为示意
                w[label] = w.get(label, 0.0) + sum(graph["adj"][u].values())
        return w

    for _it in range(max_iter):
        changed = False
        member_weight = {}                          # 每个 label 的成员权重和（防吞并用），每轮重算
        for u in nodes:
            lw = {}                                 # label -> 簇权重和
            for _m in nodes:
                lw.setdefault(labels[_m], 0.0)
                lw[labels[_m]] += sum(graph["adj"].get(_m, {}).values())
        # 注：上段为说明；实现时在每轮开头一次性预计算 label→weight 字典，O(V+E)
        for v in nodes:                             # 固定升序遍历（seed 决定的是平局与初始化扰动，
            neigh = graph["adj"].get(v, {})         # 本实现无随机性，seed 仅作接口保留）
            if not neigh:
                continue
            votes = {}                              # label -> Σ Sim(u,v)
            for u, sim in neigh.items():
                votes[labels[u]] = votes.get(labels[u], 0.0) + sim
            best = max(votes.values())
            candidates = sorted(c for c, s in votes.items() if abs(s - best) <= FLOAT_EPS)
            if len(candidates) > 1:                 # 平局规则 1：取簇规模大者
                size = {}
                for _m in nodes:
                    size[labels[_m]] = size.get(labels[_m], 0) + 1
                candidates.sort(key=lambda c: (-size.get(c, 0), c))   # 平局规则 2：规模同取 label 小者
            new_label = candidates[0]
            if new_label == labels[v]:
                continue
            # 防吞并：新簇权重和必须 > 当前簇权重和 × anti_absorb 才允许迁移
            if label_weight.get(new_label, 0.0) <= label_weight.get(labels[v], 0.0) * anti_absorb + FLOAT_EPS:
                continue
            labels[v] = new_label
            changed = True
        if not changed:
            break
    return labels
```

实现注意（照此修正上方示意段）：

1. **每轮开头预计算** `label_weight: dict[int, float]`（label → 成员度数权重和 ΣΣsim）与 `label_size: dict[int, int]`，各 O(V+E)；节点循环内只做查表，避免嵌套重算。
2. **迭代序固定为 book.id 升序、同步更新**（即本轮内后遍历的节点能看到先遍历节点的新标签，asynchronous LPA）——这是收敛更快且确定的选择；必须在测试中断言「换序结果不变」不成立是允许的，但**同一序永远复现同一结果**。
3. **seed 语义**：本实现无随机源，seed 参数仅保留接口（未来若引入随机抽样遍历可复用），文档注明「seed=0 即完全确定」。
4. **收敛判定**：`changed == False` 或达到 `max_iter`。达 max_iter 时取当前 labels（实践中加权+防吞并下 ≤6 轮收敛；单测需覆盖）。
5. **后处理**：`MIN_CLUSTER = 1`（单书簇合法，归「其他」由上层决定）；labels 归一化：把每个 label 映射到该簇最小成员 id，保证「同构图不同初始 id 集合」输出可比较。

### Step 4：虚胖簇分裂守卫

**输入**：`graph`、成簇结果 `assign: dict[int, int]`（label 或分量根）。
**输出**：细化后的 `assign`。
**复杂度**：每层 O(m²)（m 为簇规模）；深度上限 2，总量 ≤ 全图一次重算。
**失败回退**：递归中任何异常 → 保留分裂前的簇（守卫是改进项，不能把聚类弄坏）。

```python
def _split_bloated_clusters(db, graph, assign, tau_cluster, max_depth=2):
    def avg_inner_sim(members):
        if len(members) < 2:
            return 1.0                              # 单点簇不判虚胖
        total, cnt = 0.0, 0
        for i, a in enumerate(members):
            for b in members[i + 1:]:
                total += graph["adj"].get(a, {}).get(b, 0.0)   # 无边记 0，拉低均值
                cnt += 1
        return total / cnt

    def recut(sub_nodes, depth):
        if depth > max_depth or len(sub_nodes) < 4:
            return [sorted(sub_nodes)]              # 小簇/到深度上限：不再切
        sub = _induced_subgraph(graph, sub_nodes)   # 只保留 sub_nodes 间的边（新函数，O(E_sub)）
        groups = _connected_components(sub)         # 基线路径；若启用 LPA 则同样走 flag 分支
        if len(groups) == 1:                        # 子图仍连通 → 无法用分量切开
            return [sorted(sub_nodes)]              # 停止（不做更细的谱切，避免引入依赖）
        out = []
        for g in groups:
            if avg_inner_sim(g) < tau_cluster * BLOAT_FACTOR:   # 递归判虚胖
                out.extend(recut(g, depth + 1))
            else:
                out.append(g)
        return out

    result = dict(assign)
    label_groups = {}
    for book_id, lab in assign.items():
        label_groups.setdefault(lab, []).append(book_id)
    next_label_seed = max(assign.values()) + 1 if assign else 1
    for lab, members in sorted(label_groups.items()):
        if avg_inner_sim(sorted(members)) >= tau_cluster * BLOAT_FACTOR:
            continue                                # 不虚胖，跳过
        new_groups = recut(sorted(members), 1)
        if len(new_groups) <= 1:
            continue                                # 切不开，维持原簇（记录日志计数即可）
        for idx, g in enumerate(new_groups):
            new_lab = lab if idx == 0 else next_label_seed
            if idx > 0:
                next_label_seed += 1
            for m in g:
                result[m] = new_lab
    return result
```

要点：

- **虚胖判据**：簇内平均两两 Sim < τ_cluster × 0.8（=0.08）。无边成员对按 0 计入分母——这正是现行「8 书挤函数」的形态（大量成员对其实无直接边，靠传递性粘连），切开后自然分裂为多个连通块。
- **递归深度上限 2**、最小簇规模 4：防止病态数据上无限递归；深度与规模下限写为 thresholds 常量便于评估集调参。
- **子图重切只用子图边**（`_induced_subgraph`），不与外部节点交互——保证守卫是纯局部操作、结果确定。

## 3. 增量更新路径

### 3.1 新书导入（不回卷已定簇）

**入口**：`incremental_cross_book_graph`（cross_book.py:112）中现行 `assign_clusters(db, [book, *others])` 调用保留（它走缓存+增量），另新增 `_cluster_book_incremental` 供其内部调用；也可由 `assign_clusters` 内部在「仅 1 本 pending 且缓存分层键有效」时短路到本路径。

**输入**：新书 `book`、全库既有书的向量与缓存簇。**输出**：该书簇名 + 动作标记。

```python
def on_book_added_incremental(db, book_id):
    book = db.get(Book, book_id)
    w_new = idf_vector(canonical_terms(book_keywords(book, 80)))
    if not w_new:
        return {"action": "isolated", "cluster": "其他"}

    cache = _load_cluster_cache()
    if not _cache_head_valid(cache):                  # algo/lexicon/idf 任一变 → 放弃增量，走全量
        assign_clusters(db); return {"action": "full_recompute"}

    others = [b for b in db.query(Book).filter(Book.id != book_id).order_by(Book.id)]
    best_cluster, best_sim = None, 0.0
    absorbed = []                                     # 「其他」中可被吸附的书
    for ob in others:                                 # id 升序，确定性
        sim, _terms = _sim_cached(db, book, ob, w_new, idf_vector_of(ob))
        if sim is None:
            continue
        c = cache["books"].get(str(ob.id), {}).get("cluster") or "其他"
        if sim + FLOAT_EPS >= TAU_CLUSTER:
            if c != "其他" and sim > best_sim + FLOAT_EPS:   # 严格大于，平局取先遇（id 小者）
                best_cluster, best_sim = c, sim
        elif c == "其他" and sim + FLOAT_EPS >= TAU_CLUSTER * BLOAT_FACTOR:
            absorbed.append((ob.id, sim))             # 弱关联的孤儿，可作种子吸附

    if best_cluster:                                  # 情形 1：并入最佳簇（只改新书落盘）
        _write_classify(db, book, best_cluster, "pre", version_of(book))
        _cache_update_one(cache, book_id, best_cluster)
        return {"action": "joined", "cluster": best_cluster}

    if absorbed:                                      # 情形 2：新书作种子，局部吸附其他「其他」书
        cluster_name = _name_singleton_cluster(db, book, [books_by_id[i] for i, _ in absorbed])
        for bid, _s in absorbed:                      # 仅局部两两，不回卷已定簇
            _write_classify(db, books_by_id[bid], cluster_name, "pre", ...)
        _cache_update_many(cache, [book_id, *[i for i, _ in absorbed]], cluster_name)
        return {"action": "seed", "cluster": cluster_name}

    _write_classify(db, book, "其他", "pre", ...)      # 情形 3：孤立
    _cache_update_one(cache, book_id, "其他")
    return {"action": "isolated", "cluster": "其他"}
```

**关键约束**：

- **绝不触碰既有非「其他」簇的成员归属**（不回卷）；新书只能「并入」或「在孤儿堆里建种子簇」。
- **局部两两**只发生在「其他」集合与新书之间；若「其他」集合 >50，吸附判定只对与新书 Sim 最高的前 20 名做（上限常量 `SEED_SCAN_CAP=20`）。
- 并入判定用**严格大于 + 容差**，平局取 book.id 较小的既有书所在簇（升序遍历先遇者），保证确定性。
- 回退：缓存头失效或任何异常 → 调全量 `assign_clusters`（正确性优先于性能）。
- 复杂度：O(N·k̄)（新书对全库各算一次 Sim），300 书 <50 ms。

### 3.2 归档 / 删书：受影响分量的局部重算

**背景事实**：删书（books_service.py:43-59）已级联删除该书的 `BookRelation` 与 `KnowledgePoint`，但**不触发簇重算**；归档走 `post_classify_book` + `merge_and_rename_clusters`（rag_service.py:95）。删书可能把一个连通分量切成多块（该书是「桥」时），必须检测。

**输入**：被删/被归档书 id、缓存中的簇归属。**输出**：受影响簇的更新结果。

```python
def on_book_removed(db, removed_book_id):
    cache = _load_cluster_cache()
    if not _cache_head_valid(cache):
        assign_clusters(db); return {"recomputed_components": -1}
    entry = cache["books"].pop(str(removed_book_id), None)
    if entry is None:
        _save_cluster_cache(cache); return {"recomputed_components": 0}
    affected = entry["cluster"]
    members = [int(bid) for bid, e in cache["books"].items()
               if e["cluster"] == affected and e["cluster"] != "其他"]
    if not members:                                   # 该书是簇内唯一成员，直接清缓存
        _save_cluster_cache(cache); return {"recomputed_components": 0}

    # 1) 分裂检测：用剩余成员重建子图，看连通分量数
    books = db.query(Book).filter(Book.id.in_(members)).all()
    vectors = {b.id: idf_vector_of(b) for b in books}
    sub = _build_sim_graph(db, books, vectors)        # 不含已删书 → 边集自动更新
    groups = _connected_components(sub)
    isolated = [m for m in members if not sub["adj"].get(m)]   # 变孤儿的成员

    if len(groups) <= 1 and not isolated:             # 未分裂：只更新缓存（成员数变化影响簇名）
        _save_cluster_cache(cache); return {"recomputed_components": 1}

    # 2) 分裂处理：最大块沿用原簇名；其余块重新命名（走 Step 5 命名链）；孤儿归「其他」
    groups.sort(key=lambda g: (-len(g), g[0]))        # 规模降序，同规模取最小 id 在前（确定性）
    keep, rest = groups[0], groups[1:]
    _rename_and_persist(db, rest, cache)              # 每块 _pick_domain_name → 写 DB + 缓存
    for m in isolated:
        _write_classify(db, books_by_id[m], "其他", "pre", ...)
        cache["books"][str(m)]["cluster"] = "其他"
    _save_cluster_cache(cache)
    # 3) 触发受影响簇与相邻簇的局部 merge 检查（见 3.3）
    return {"recomputed_components": 1 + len(rest)}
```

**要点**：

- **分裂检测方法**：对「受影响簇的剩余成员」重建诱导子图 + 连通分量；分量数 >1 或出现孤儿 = 已分裂。无需保存旧边集，子图重建成本 O(m²)，m 为该簇规模（典型 <30，毫秒级）。
- **命名稳定性规则**：最大连通块继承原簇名（用户可见名称不跳变）；被切出的小块重新命名；规模相同时取含最小 book.id 的块继承——全部确定性规则。
- **归档（非删书）路径**：书还在，走现行 `post_classify_book`（tag/文件夹硬约束 + τ_post 校验，P1 已改 Sim_post ≥ 0.15）；迁簇时只改该书落盘，然后调 `merge_clusters_local(db, {旧簇, 新簇})`。

## 4. 确定性、缓存与性能

### 4.1 结果可复现保证（三条硬规则 + 容差）

| 规则 | 落实点 |
| --- | --- |
| 遍历序一律 book.id 升序 | 成图上三角、并查集 `components()`、LPA 节点扫描、增量扫描、merge 簇序全部 `sorted(...)`；禁止依赖 dict 插入序或 DB 无序查询（凡 DB 查询必须 `order_by(Book.id)`） |
| 无随机源 | LPA 不引入 `random`；seed 参数仅接口保留；并查集秩同时取较小 root |
| 平局规则显式 | LPA 投票平局：簇规模大者 → label 小者；增量并入平局：先遇者（id 小）；删书分裂继承平局：含最小 id 的块 |
| 浮点容差 | 一切阈值比较用 `a >= b - FLOAT_EPS`（`FLOAT_EPS = 1e-9`）；「相等」判定 `abs(a-b) <= FLOAT_EPS`；Sim 值在入图前 `round(sim, 6)`，消除跨平台浮点尾差 |

**验收**：同库连续两次全量聚类结果逐 book 相等；3 种导入顺序结果一致（§5.1）。

### 4.2 缓存分层失效判定（决策树，按序短路）

```
读缓存 →
  1) 缺文件 / JSON 损坏 / 非 dict            → 全量重算（现行行为保留）
  2) algo_version != 2                       → 全量重算（算法升级一次性重算）
  3) lexicon_sig 变化（词库/别名表被编辑）     → 全量重算（低频显式操作，可接受）
  4) idf_sig 变化（书数或 df 表哈希变化）      → 全量重算（书增删必然触发，等价于群体失效，
                                                 但注意：增量路径 3.1/3.2 在写缓存时同步刷新
                                                 idf_sig，使「读时」总是一致的；此分支主要兜底）
  5) 头全部一致 → 逐书比较 books[id].sig：
       sig 一致 → 命中，直接采用缓存 cluster
       sig 变化 → 该书走增量重判（3.1 路径），不回卷其他书
  6) books 中缺失的新书 → 走 3.1 增量并入
POST /rebuild（rebuild_all_graph）→ 无条件全量重算并覆盖写缓存（现行强制刷新语义保留）
```

签名来源复用：单书签名 = `_cluster_signatures`（clustering.py:70-94，已覆盖 content_hash/标题/作者/tag/文件夹/classify 版本）；`lexicon_sig` = 词库文件内容 + 别名表行集合的 sha256[:16]；`idf_sig` = `sha256(f"{N}|{sorted(df.items())}")[:16]`。

### 4.3 复杂度与预算（300 书，k̄≈70）

| 环节 | 计算量 | 时间估算（纯 Python） |

### 5.5 增量并入 / 删书分裂用例

1. **并入**：新书与既有簇某成员 Sim ≥ τ_cluster → 断言新书落入该簇、既有成员簇名零变化、缓存仅新增一条；

## 风险与备注

1. **LPA 默认关**：P2 基线只上连通分量 + 分裂守卫（行为最可预测）；LPA 由 flag（建议 `settings.cluster_use_lpa: bool = False`）控制，评估集证明收益后再默认开。
2. **IDF 依赖 P1**：本设计的 Sim 全部假定 P1 的 `canonical_terms`/IDF 已落地；若 P2 先于 P1，成图退化为「现行 min 余弦 ≥ 0.10 等效阈值」，连通分量仍成立但 D1 缓解打折——发布顺序必须 P1 → P2。
3. **缓存结构一次性破坏**：升级后首次打开谱系图全量重算（12 书毫秒级、300 书秒级），无需迁移脚本；但若用户回滚版本，旧代码读到新结构会因缺 `population` 键而视为损坏全量重算——双向安全。
4. **删书入口唯一化**：`on_book_removed` 必须由 `books_service.delete_book`（books_service.py:43）在 `repo.delete_book` 成功后调用；若存在其他删书路径需一并挂接（当前检索仅此一处 API 入口，`DELETE /books/{book_id}`）。
