## 二、浏览器实测问题（按页面分节）

### 2.1 首页书架（/）

#### 1-1 Element Plus 未配置中文 locale（P1）
- **问题描述**：下拉空态显示英文 "No data"，标签编辑弹层内多选空态同样英文（视觉/i18n，严重度：中）。证据：DOM 检查 `.el-select-dropdown` innerText="No data"；页面同时有 13 组预挂载 popper。
- **改进方法**：在 `frontend/src/main.ts`（或 `App.vue` 根部）用 `<el-config-provider :locale="zhCn">` 包裹应用，`import zhCn from 'element-plus/es/locale/lang/zh-cn'`；当前 `main.ts` 仅 `app.use(ElementPlus)` 未传 locale。

#### 1-2 任务中心失败任务"查看详情"点击无响应（P0）
- **问题描述**：失败任务"▼ 点击查看详情"点击无任何响应（无展开、无请求），用户看不到错误详情；而后端 API 中存有友好文案"服务重启，任务中断，请重新提交"（交互，严重度：高）。证据：多次真实/脚本点击均无效；GET /api/tasks 返回 error 字段内容完整。
- **改进方法**：与 1-3 疑似同一根因（Vue transition 被 /api/tasks 高频轮询打断）。① 排查 `frontend/src/components/TaskCenter.vue` 的 `<transition>` 与轮询数据更新的时序，轮询回包若整体替换任务数组会导致节点 key 变化、过渡 enter/leave 互相打断；② 失败详情改用**可展开列表项**（自管 `expandedTaskId` 集合 + `v-show`/高度动画），不再依赖浮层过渡；③ 浮窗展开期间暂停或降频轮询。

#### 1-3 任务中心折叠按钮无响应、过渡类堆叠卡死（P1）
- **问题描述**：折叠 ▾ 按钮点击无响应；组件 class 出现 `task-fade-enter-from task-fade-leave-from task-fade-leave-active` 过渡类堆叠卡死（enter 与 leave 状态共存）（交互/流畅度，严重度：中）。证据：点击后高度仍 206px、内容不变；className 检查。
- **改进方法**：同 1-2 根因排查（`TaskCenter.vue`）。具体措施：为 `<transition>` 内节点提供稳定 `:key`；折叠态切换改用 `v-show` 而非 `v-if`+transition；必要时对该过渡加 `:duration` 或改 CSS-only 动画，避免 JS 过渡被响应式更新打断。

#### 1-4 删除确认弹窗过渡卡死、跨路由残留（P1）
- **问题描述**：ElMessageBox 过渡同样卡死（enter-from+leave-from 共存），弹窗 DOM 残留、跨路由导航后仍留在阅读页上，需二次取消（交互，严重度：中）。证据：/reader/13 页快照中仍存在"删除书籍"弹窗；overlay class 检查。
- **改进方法**：疑似与 1-2/1-3 同根因（高频轮询打断 transition）。① 验证修复 1-2 后本问题是否随之消失；② 若仍复现，在 `frontend/src/views/HomeView.vue` 删除流程改为组件内 `el-dialog`（随视图卸载而销毁），不再用命令式 `ElMessageBox`；③ 在 `router/index.ts` 全局 `beforeEach` 中兜底关闭残留遮罩。

#### 1-5 状态语义不一致、头部统计遗漏未读（P2）
- **问题描述**：《Fixed Income Securities》标"在读"但进度 0/538；头部统计"共12本 · 2读完 · 8在读"未显示 2 本未读（2+8≠12）（视觉/数据，严重度：低）。证据：a11y 快照徽章与统计文本。
- **改进方法**：在 `frontend/src/views/HomeView.vue` 统计 computed 中补齐"未读"分类并展示（共 X · Y 读完 · Z 在读 · W 未读）；徽章状态派生逻辑统一（进度为 0 且无阅读记录应显示"未读"），可下沉到 `frontend/src/stores/book.ts` 的 getter。

#### 1-6 缺少排序控件（P2）
- **问题描述**：工具区仅搜索、标签筛选、拖拽换位，无法按进度/书名/最近阅读排序（交互，严重度：低）。证据：DOM 中无"排序/sort"相关元素。
- **改进方法**：在 `HomeView.vue` 工具区增加 `el-dropdown` 排序选择器，对展示列表做 computed 排序（进度复用 `frontend/src/utils/progress.ts` 的 `percentOf`）；排序偏好持久化到 localStorage。

#### 1-7 超长书名/最新章节未截断（P2）
- **问题描述**：超长书名与"最新章节"行未截断，卡片高度参差（如"第1章 ——从线性方程组与 Hamilton–Cayley 定理出发的一份讲义"）（视觉，严重度：低）。证据：快照文本。
- **改进方法**：卡片标题/最新章节加 CSS `-webkit-line-clamp`（2 行截断 + `title` 属性全文悬浮提示）；随 A-5 拆分落到新的 `BookShelfCard.vue` 中实现。

#### 1-8 书架每本书预挂载 2~3 个 popper（P2）
- **问题描述**：每本书预挂载 2~3 个 body 级 popper（标签下拉 + 编辑弹层），12 本约 36 个；长书架会线性膨胀（流畅度，严重度：低）。证据：querySelectorAll('.el-select-dropdown, .el-popper') 计数。
- **改进方法**：将"标签编辑弹层"从每卡片实例改为 `HomeView.vue` 级**单一共享弹层**（点击卡片时传入 bookId 打开）；卡片内 `el-select` 按需渲染（`v-if` 仅在编辑态挂载），消除每卡预挂载。

#### 1-9 "最近完成"列表语义不准（P2）
- **问题描述**：任务中心标题"最近完成"但列表含失败任务，标签语义不准；失败态长期驻留且无单独移除入口（视觉，严重度：低）。证据：快照。
- **改进方法**：`TaskCenter.vue` 标题改为"最近任务"或分两组（进行中/已完成、失败单列）；失败条目提供单条移除按钮（本地移除即可，后端已有 RETENTION_DAYS=7 自动清理）。

### 2.2 阅读页（/reader/13 MD 书、/reader/8 PDF 书）

#### 2-1 AI 对话挂起无反馈、原始技术错误直接暴露（P1）
- **问题描述**：提问后挂起 40+ 秒仅显示"思考中…"，无进度/预计时长/超时提示；点击"停止"后聊天气泡直接显示原始技术错误 "BodyStreamBuffer was aborted"，用户无法理解（交互，严重度：高）。证据：实测计时；停止后 innerText 含该错误串。
- **改进方法**：① `frontend/src/components/ReaderChatPanel.vue` / `frontend/src/composables/useReaderAi.ts` 增加已等待计时与"仍在生成中…"阶段文案、客户端超时兜底（如 120s 提示重试）；② 在 `frontend/src/api/chat.ts` 的 SSE 错误处理中做错误映射：abort 类错误（含 "BodyStreamBuffer was aborted"）转为"已停止生成"，不向用户展示原始技术串；③ 主动停止时不应落一条错误气泡，改为将当前消息标记为"已停止"。

#### 2-2 POST /api/books/8/progress 返回 404，进度静默丢失（P0）
- **问题描述**：POST /api/books/8/progress 返回 404（GET 同名接口 200），进度保存静默失败、UI 无任何提示（技术/交互，严重度：高）。证据：网络 reqid=157 failed-404；控制台 404 错误。
- **改进方法**：① 核对 `backend/app/api/routes/books.py` 进度端点的实际方法与路径（可能为 PUT/PATCH 或带子路径），与前端请求对齐；② 前端在 `frontend/src/api/reading.ts` 收敛该请求并修正方法；③ 保存失败时必须提示（依赖 B-2 的统一错误包装），不得静默失败；④ 补 vitest 用例锁定请求方法与路径。

#### 2-3 AI 上下文注入缺陷：正文占位符未替换即发送（P0）
- **问题描述**：旧对话中 AI 回复"无法提取…因为'当前章节正文'显示为'未发送'"——正文占位符未替换为真实内容即发送给模型，上下文注入缺陷的直接证据（交互/功能，严重度：高）。证据：/reader/8 AI 面板历史消息。
- **改进方法**：① 排查 `frontend/src/composables/useReaderAi.ts` 组装上下文时机（章节正文异步未就绪时不得先发消息）与后端 `backend/app/services/chat_service.py` 提示词注入逻辑，确保占位符在发送前必被替换或显式声明"暂无正文"；② 增加发送前断言：检测到残留占位符（如"当前章节正文"/"未发送"）时阻断请求并提示；③ 补回归测试（后端 pytest + 前端 vitest 各一条）。

#### 2-4 PDF 目录无虚拟滚动（P1）

#### 2-6 页缓存覆盖极低时无重建引导（P2）

### 2.3 图谱页（/graph）

- **改进方法**：在 `frontend/src/router/index.ts` ① 增加 `/:pathMatch(.*)*` 兜底路由（渲染 NotFound 视图并引导回首页）；② 增加 `/graph/:bookId` 路由，复用 GraphView 并据参数定位到对应书内图谱（或 redirect 到 /graph 并自动选中该书）。

#### 3-3 ECharts legend 引用不存在的 series（P2）
- **问题描述**：ECharts 警告 ×3："章节级/重要段落/用户标记 series not exists. Legend data should be same with series name"——空层级时 legend 引用了不存在的 series（技术，严重度：低）。证据：console warn msgid=15-17。
- **改进方法**：在图谱 option 拼装处（现 `GraphView.vue`，建议随 A-1/B-6 提取为 `buildForceGraphOption` 纯函数）按实际数据过滤 legend.data，仅保留存在对应 series 的层级。

- **改进方法**：根因在后端聚类命名（`backend/app/services/graph/clustering.py` 的领域标签生成），建议补充术语映射/翻译；前端可在 `GraphView.vue` 渲染前做展示层映射兜底。

#### 3-5 近乎空图谱无重建引导（P2）
- **问题描述**：《变分法基础》图谱仅 1 章节/1 知识点/0 关系，近乎空图但无提示引导重建（交互，严重度：低）。证据：/graph 书内视图快照。
