### 10.2 图谱 API（`backend/app/api/routes/graph.py`，prefix `/api/graph`）

- `GET /books`：书籍级谱系图（懒构建：尚无关联时自动计算一次）→ `{clusters, nodes, edges}`；边字段含 `strength / direction / from_book / relation_type / reasons / user_feedback`（`from_book` 为有向边理论源头书 id，v1.32）。
- `GET /books/{book_id}`：书内知识图谱（懒构建）→ `{nodes, edges, chapters}`。
- `POST /rebuild`：重建全部图谱（同步）。
- `POST /books/{book_id}/rebuild`：重建单书内部图谱。
- `POST /relations/{relation_id}/feedback`：人工反馈 `{action: 确认/忽略/修改, strength?}`，回写 `user_feedback` 与强度。

### 10.4 图谱标签与 tooltip 的 LaTeX/Markdown 渲染（`frontend/src/utils/graphLabel.ts`，v1.79）

- 背景：谱系图节点名（书内知识点常含 `$` 与 `**md**`）、关联原因等多由 LLM 生成，ECharts 原生标签会裸露原文；统一改为「公式渲染为图片 + Markdown 清洗为文本」。
- 公式图片：KaTeX 无 SVG 输出能力，改用 **MathJax tex2svg**（`mathjax-full`，动态 import 按需加载，仅图谱页拉取）把公式转成 SVG data URL，嵌入 ECharts 富文本 `backgroundColor.image`；MathJax 对非法公式输出 `data-mjx-error` 错误 SVG，检测到即回退纯文本。
- 工具函数（`frontend/src/utils/graphLabel.ts`）：
  - `ensureGraphLabelReady()`：一次性预加载 MathJax + KaTeX + markdown-it + DOMPurify（`loadGlobal`/`openIntraBook` 开头 await）。
  - `formulaToImage(latex, fontSize=10)`：LaTeX → `{url, width, height}`（data:image/svg+xml），带缓存；失败返回 `null`。
  - `stripMarkdown(text)` / `splitLabelSegments(raw, fontSize)` / `labelRichFormatter(raw, fontSize, maxChars=12)`：切分「文本段 + 公式段」（支持 `$..$`、`..`、`\(..\)`、`\[..\]`、裸 `\command` 段，单标签最多 2 个公式），**v1.80 起返回 `{ formatter: string, rich }`**：formatter 为「文本直接拼接 + `{fN| }` 公式 token」的字符串，rich 为 token→图片样式表；文本截断加 `…`。
  - **为什么不用对象 formatter（v1.80 修复 `[object Object]`）**：graph 系列 label formatter 若返回对象（`{rich, formatter}` 数组），ECharts 直接把对象写入 zrender `style.text`，zrender 的 `getStyleText`/`parseRichText` 会执行 `text += ''` 字符串化，导致所有节点名渲染成 `[object Object]`；`overflow:'truncate'`/`width` 只是加剧该问题。修复：formatter 只返回字符串，rich 样式表挂到**每个数据项的 `label.rich`**（`GraphView.vue` 的 `data`/`links` 映射中 `label: { formatter, rich }`），系列级 label 只保留 `show/position/fontSize`。边标签（edgeLabel）同样处理。
  - `renderTooltipHtml(src, inline)`：Markdown + LaTeX → 消毒后 HTML（公式占位保护 + markdown-it + KaTeX 内联 + DOMPurify）。
- GraphView 接入点：全局/书内节点 label、全局边 label（`X分 原因`）、tooltip、关联详情/知识点详情弹窗（`<MdRender>`）。
- 修改提示：字号 `LABEL_FONT_SIZE`（默认 10）、文本截断 `MAX_TEXT_CHARS`（默认 12）、公式上限 `MAX_FORMULAS`、ex→px 比例 `MATHJAX_EX_RATIO=0.442`（MathJax font.params.n）；新增依赖 `mathjax-full`（`pnpm add mathjax-full`）。

| 函数 | 功能 | 使用/修改 |
| --- | --- | --- |
| `get_thresholds(db)` | 读取当前阈值 `{warm_threshold, related_strength, review_days}`（`settings` 表持久化优先，未设置回默认常量 3/60/1） | `relatedness.is_related_book`/`migrate_profiles_on_archive`、`recommendation_service` 统一走此函数 |

| `record_archive(db, archived_at)` | 归档时记录节奏样本（相邻归档间隔天数，保留最近 24 条） | `migrate_profiles_on_archive` 自动调用 |

| `learn_thresholds(db)` | 自动学习：归档样本 ≥6 → 间隔中位数定 `review_days`、节奏快慢定 `warm_threshold`；`related_strength` 取**行为样本 25% 低分位与确认边 25% 低分位之较小者**（行为样本 ≥6 或确认边 ≥3，裁剪 45~60）；样本不足仅记录时间戳不改阈值 | 画像页「立即按样本学习」按钮 / 归档自动触发；学习规则改此处 |
| `learning_state(db)` | 学习状态视图（归档样本数/相关度样本数/上次学习时间/已学阈值/样本下限） | 随 `GET /api/profile/thresholds` 返回 |

- **API**：`GET /api/profile/thresholds`（阈值+学习状态）、`PATCH /api/profile/thresholds`（手动覆盖）、`POST /api/profile/learn`（立即学习）。
