## 1. 结论摘要

1. **时机：基本成熟，缺 3 个拍板项**。算法决策层（O1~O10）2026-08-05 已全部定稿，demo 闭环验证完成（三路对比矩阵/验收案例/文本层/评估自动化）；正式版代码零改动属实。唯一硬阻塞 = **表结构与迁移未敲定**（`term_aliases` 表）；另有 2 个小参数需定稿：**IDF_CUT（0.5 vs 0.7）**、**RAG 文本层切换后 `book_keywords` 下游漂移冻结点**。评估集 12→30 本未达标**不阻塞** P1/P2 基线，只阻塞增强项（bloat 自适应/LPA 默认开/jieba）。
2. **功能：demo 脚本健全，正式版引擎不健全**。demo 零依赖、确定性、corpus 模式 7 条结论精确复现；但正式版聚类引擎仍是 demo 判定失败的版本（贪心吸收 D1、顺序敏感 D3、min 伪余弦 D4、强度只升不降 D5、方向全靠猜 D6），O1~O10 零落地。发现 2 个 demo 小缺陷（`--report` 非 AC 算法缺逐书归属表；`--from-db` 缺省库路径依赖运行目录）。
3. **预期目标：基本健全有缺口（16 项目标中 12 项可达成/部分达成，4 项正式版完全缺位）**。缺位项：T4 分层钻取（领域层→书籍层两级）、T8 交叉领域标签、T10 阅读路径子页面、T13 正式版评估闭环。词面算法不可达项：中英同域桥接（K5，recall 上限 0.75，需 LLM 层或用户 tag 兜底）。
4. **重要新事实（实测发现）**：DB 语料已从 13/14 本漂移到 **20 本**（24~30 七本无金标），文档中全部 `--from-db` 指标已过期（推荐配置 pair-F 0.286→0.200）；**LPA 反超在 20 本 tau≥0.20 重现**（tau=0.25：LPA 0.286 vs AC 0.200），「反超不复现」仅适用于 14 本快照 → K6/O1 需在冻结评估集上重评。
5. **建议**：先拍板 3 项 → 按 L0~L5 顺序落地（L0 表结构/迁移 → L1 同义词解析+terms.py → L2 IDF 余弦+thresholds.py → L3 RAG 文本层 → L4 P2 成簇引擎 → L5 验收测试）；P2 验收挂三道硬门槛（顺序稳定性 / 12 本金标 pair-F 不降 / 20·22 号人工目检）。

## 4. 建议落地顺序（L0~L5）

1. **L0 表结构/迁移敲定（0.5~1 天决策）**：`term_aliases` model + create_all + `ix_aliases_canonical` 索引。
2. **L1 同义词区解析（P1 核心）**：`load_domain_lexicon` 扩展三段式解析（用户区/同义词区/系统缓存区）+ 用户区优先级 + 写路径兼容；新增 `terms.py::canonical_terms`（长词优先/内部 token ×0.3）。
3. **L2 IDF 余弦 + 阈值集中化（P1）**：`_pair_score` 核心抽 `pair_similarity` 共享函数（聚类/建边共用）；新建 `thresholds.py`（τ_edge 0.06 / τ_cluster 0.10 / τ_post 0.15 / τ_merge 0.35 / BLOAT_FACTOR 0.8）；IDF_CUT 定稿；post-classify 换 Sim_post≥0.15。
4. **L3 RAG 文本层抽取（P1，K1）**：章节标题×2+正文×1+RAG×3、扫描书回退书名；冻结 `book_keywords` 下游行为。
5. **L4 P2 成簇引擎**：缓存分层键 → 成图/并查集连通分量 → 分裂守卫 → 增量并入/删书分裂/局部 merge → settings 配置位（BLOAT_FACTOR/cluster_use_lpa）。
6. **L5 P2 验收**：顺序稳定性测试、12 本金标 pair-F 回归、20/22 号人工目检、性能门禁（300 书 <30s）。

## 5. 风险提示

- 基线不稳：`cross_book.py` 有在途未提交改动（P0 倒排缩进修复），开工前先提交并全量跑图谱套件。
- 删书入口唯一化：`on_book_removed` 需挂 `books_service.delete_book`（P2 复核）。
- B 组拆分：`assign_clusters`/`merge_and_rename_clusters` 拆分等 P2 替换后做（与待办清单一致，无需提前）。
