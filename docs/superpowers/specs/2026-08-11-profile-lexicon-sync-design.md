# 「领域偏好修复 → 词库沉淀」联动设计（v1.134）

> 日期：2026-08-11 ｜ 状态：待实施 ｜ 前置：v1.133 领域偏好 RAG 重建（jieba 画像术语层）

## 1. 背景与目标

v1.133 起「重新生成画像」从书库 RAG 资产重建领域偏好（每本 top15 → 聚合 top60）。重建过程已产出高质量领域词（如「角动量」「自伴」「反常积分」），但未回流到 `domain_terms.txt` 词库——词库只靠聚类命名与用户手动维护，无法从画像重建中获益。

目标：**正反馈闭环**——重建中的高频领域词自动沉淀进词库系统缓存区，后续 jieba 切词更准、聚类命名更专业、下次重建质量更高。

## 2. 设计

`profile_service._rebuild_domain_preferences` 内新增联动：

1. 抽取时记录**词 → 覆盖书数**（`book_coverage`：多少本书的抽取结果包含该词）；
2. 重建结束后，对「覆盖书数 ≥ 2 **且** 进入最终 top60 偏好」的词调用 `cache_domain_term(term)`（lexicon.py 既有机制：写入系统缓存区、原子替换、已存在则跳过、泛化词不缓存）；
3. 词库写入失败（文件锁/IO）不阻塞重建（try/except 吞掉，保持 refresh 幂等安全）。

## 3. 向前兼容

- 只**追加**不删除：词库用户区与既有缓存区不受影响；用户仍可手动编辑/删除自动沉淀的词；
- 频率受控：仅用户主动点「重新生成」时触发（非归档热路径），且只写「覆盖 ≥2 本书」的强领域词，防低频词污染；
- 无信息丢失：重建结果不变，词库沉淀是纯增量副作用。

## 4. 测试计划

- 造 2 本带 RAG 的书共享领域词（如「变分法」）→ refresh → 断言 `DOMAIN_TERMS_FILE`（测试隔离临时词库）包含该词；
- 单本书独有词（覆盖 1 本）不沉淀；
- 词库已存在该词时重复 refresh 不重复写入（幂等）。
