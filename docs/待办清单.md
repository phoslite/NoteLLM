- **定稿（2026-08-05）**：主路线 **A+C 组合**——术语归一化 + IDF 加权解决输入质量，自研连通分量 + 分裂守卫解决成簇结构；B 文本向量降级为可选辅助信号（feature flag 默认关，仅预留配置位）；LLM 定位为**离线修正层**（别名生成 / 簇命名 / 方向证据抽取 / 打分增强），不进入聚类主循环；正式版聚类代码零改动（需求-决策 9.2-2）。
- **demo 已实现（两层分离）**：`canonical_terms` 纯别名折叠（聚类输入）+ `inject_lexicon` 命名层注入（100 权重 / 内部 token ×0.3 / 长词优先，仅命名用）；`--input` / `--no-synonyms` / `--eval` / `--bloat`；`demo/export_real_corpus.py` 导出 11 本真实库；`demo/gold_clusters.json` 金标 9 簇（20 号书修正为「自然种类」）。
- **验收达成**：20 号书（在世界的关节处下刀）tau=0.15/0.20 独立成簇并命名「自然种类」（哲学）；tau=0.10 与 16 合并（「聚类」备选）；A 现行贪心任何 tau 均无法验收（吸进 8 书大簇）。
- **实测结论（12 本）**：分裂守卫 bloat=1.2 在 tau=0.15 拆出 线性代数{15}、金融数学{18,22}（纯度 0.881→0.926、最大簇 7→3）；PDF 字级二元组 / LaTeX-SVG 记号使同义词折叠失效，金标对 {17,22}（英文 vs 中文金融书）词面不可达 → recall 上限 0.75；**12 本时 C LPA 反超**（tau=0.10/0.15 达 0.250/0.267，防吞并守卫抢出 变分对/金融对），O1「LPA 默认关」需在评估集扩充后重新评估；完整矩阵见 知识图谱聚类算法-改进方案 §4.2。
- **22 号书并入实测（技术分析讲义）**：与 18《金融数学核心观点》sim=0.314 合并成簇「金融数学」✓（用户按金融数学文件夹归类，与图聚类结论一致）；已正式加入 `demo/real_corpus.json`，金标 22→金融。
