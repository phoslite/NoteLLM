### 8.2 关键复核证据（简）

- **F1/F2**（真实 import 复现）：`useGlobalAi.ts:200` AbortError 判断整体跳过重置逻辑 → `streaming` 卡 true、轮询定时器存活、再次 send 被守卫拦截；`chat.ts:55-74` 读循环连接关闭即 resolve 且 `useReaderAi.ts` finally 无 `streaming=false` → 缺终态事件即永久卡死（正常 end 事件对照实验通过）。
- **F3**：同 session 同 chapter 依次问「苹果」「香蕉」，第二次 `source=cache` 且 chunks 仍为第一次结果；spy 确认命中缓存时未按新问题检索。
- **F4**：对同一书连续两次 POST summarize 返回不同 task_id；`find_active(...related_id=1)` 返回 None；两次 upsert 后 version 0→2。
- **F5**：mock `_db_write` 建行后全失败 → 行停在 `status=queued`、异常穿透 `_run_task`/`_finish`、`find_active` 仍命中 → 同类任务全部被防重卡死。
- **F6**：两簇仅共享 5 个 `_GENERIC_DOMAIN_TERMS` 泛词（定理/定义/证明/引理/推论）即被错误合并，簇名均被改为 `linear`；合并分支无泛词剔除（重命名分支有，内部不一致）。
- **F7**：`_purge_vlm` 后 jpg 全删、`page_*.txt` 全留；`read_ocr_cache(book,1)` 仍返回旧参数 OCR 文本。
- **F8/F9/F10/F14**（真实 Vue watch 语义实测）：浅监听 push/sort/下标赋值均不触发（deep 对照组触发）；F8 慢 fetch（1200ms）下空数组写入下一页、再切页永久清空+跨页错写；F14 慢加载窗口内滚动 → 旧 chapter_id 写新书进度。
